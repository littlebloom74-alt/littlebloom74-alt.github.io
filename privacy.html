Privacy Policy

For the "Pitircik Otomasyon" application used by the Little Bloom YouTube channel.

Who uses this application

Pitircik Otomasyon is a private, internal tool. Its only user is the owner of the Little Bloom channel. It is not available to the public.

Google and YouTube data we access

With the owner's explicit permission (Google OAuth), the application uses:

  • YouTube Data API Services – only to upload the owner's own finished episodes to the owner's own YouTube channel and to set their title, description, tags and audience settings.
  • Gmail API – only to send review and approval e-mails from the owner's account to the owner's own address.

The application does not read, collect or store any other YouTube or Gmail data, and it does not access data of viewers, subscribers or any third party.

How data is stored and shared

Access tokens and the generated episode files are stored only on the owner's own computer. No data is sold, shared with third parties or used for advertising. Story texts and images are generated with AI services (OpenAI and fal.ai) using only the series description written by the owner; no personal data is sent to them.

YouTube API Services

This application uses YouTube API Services. By using it, the owner agrees to be bound by the YouTube Terms of Service. Please also see the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions. Stored tokens can also be deleted directly in the application.

Data retention and deletion

Episode files are kept on the owner's computer only as long as needed to prepare and upload each episode and are overwritten by the next episode. OAuth access and refresh tokens are kept until access is revoked. When access is revoked through the Google security settings page, or on request to the contact address below, all stored tokens and any related data are deleted within 7 days. The application does not store any YouTube API data (such as statistics or channel information) beyond what is needed for a single upload.

Children's privacy

The episodes are made for children and are marked as "made for kids" on YouTube. The application itself does not collect any information from children or viewers.
